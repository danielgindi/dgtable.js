DGTable.js

A virtual table with sticky columns, resizable and movable columns, multi-column sorting, filtering, variable row heights, web worker updates, and sticky end rows: rows pinned to the bottom of the viewport, separate from the data. The first sticky end row holds filter controls. Type in it, sort, resize or move columns, and the inputs keep their value and focus. The totals and averages rows are refreshed on their own with refreshStickyEndRow(index) whenever the filtered data changes.

Sticky end rows

stickyEndRowsMode: they only differ when the rows don't fill the table. Sticky follows the last row, fixed stays at the bottom. Try it with a filter matching few rows, or 5 rows.

Without its own formatter, sticky end rows fall back to the regular cellFormatter.

Data

The web worker appends 3 rows every 2 seconds through createWebWorker().

Built-in column filter

Uses the built-in filter, filter({ column, keyword, caseSensitive }). A table has one filter function, so this and the filter row replace each other.

Sorting

Each header click adds that column to the sort, keeping up to the max. The compass order comes from setOnComparatorRequired().

Table

Changing these options re-creates the table, keeping the data and the filter. Row heights and highlights are set in rowcreate. The # column can't be moved. Double-click a column's resize edge to fit it to its content.
